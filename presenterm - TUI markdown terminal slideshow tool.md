# presenterm - How To

presenterm is a TUI presentation tool that lets you use Markdown to create presentations directly in your terminal. It supports images, GIFs, and has features like syntax highlighting and customizable themes.

Install
-----

METHOD 1. Binary release.

Download the binary from GitHub.

`curl -L -O https://github.com/mfontanini/presenterm/releases/download/v0.16.1/presenterm-0.16.1-x86_64-unknown-linux-gnu.tar.gz`

Extract the tarball.

`tar -xvf presenterm-0.16.1-x86_64-unknown-linux-gnu.tar.gz`

Copy the binary to `/usr/local/bin`

```bash
cd presenterm-0.16.1/
sudo chmod 755 presenterm
sudo cp -v presenterm /usr/local/bin/
```

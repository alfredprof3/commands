# Turn off Screen Saver

Usage
-----

List the help command available for `xset`
`xset`

List settings.
`xset q`

Turn off Display Power Management Signaling (DPMS)and screen saver.
```bash
xset -dpms
xset s off
```

Disable screen saver with `setterm` commmand.
`setterm --powersave off`
